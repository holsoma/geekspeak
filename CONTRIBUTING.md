# Contributing to Geekspeak

Use UK English and direct explanations. Do not use em dashes. A definition should help someone understand a real conversation, not replace one unexplained word with another.

For a content change, include a concrete example, a common misunderstanding and a link to original documentation. Keep the correct quiz answer unambiguous. Distractors should reflect plausible misunderstandings. Do not copy another site's definitions or quizzes.

Use Node.js 22 or later and `npm ci`. Run `npm test` and `npm run build` before submitting a change. For interactions, start the production server and run `npm run test:e2e`. Check keyboard access, mobile layout and reduced motion. Account features also need a configured development GitHub OAuth app and database.

Preserve term IDs when correcting text. Do not add streaks, time pressure, paid lives or invented leaderboard users. Do not commit credentials, real user progress, local database exports or private screenshots.

Open an issue with the term or page, what happened, and a reproducible example. Security reports should omit exploit details and credentials from public issues until the maintainer can review them.
